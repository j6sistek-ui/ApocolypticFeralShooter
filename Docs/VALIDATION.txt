KNOWN LIMITS / WARNINGS
This is a local editor test, not a packaged release or SpaceSurvival integration.
Physical controller feel, long sessions and representative performance remain
unverified. FPS hand placement is not authored; full Vexa is in the external view.
R3 barrel rolls, target lock, ammo/reloading and multiplayer are deferred.
High-altitude dismount is blocked. Exit requires speed <=3 m/s, a clear standing
capsule and walkable ground within 1.5 m of the pads. R resets Vexa and glider.
Walking L3 sprint, B crouch/prone/stand, B dive, directional walking/turning clips,
Vexa defaults/jiggle and broad lighting/material polish remain separate backlog.
DLSS, DLAA, NVIDIA frame generation and DLSS 5 are not installed/enabled in AFS;
no graphics plugin/config change was made during this physics pass.
Zombie steering is local obstacle avoidance; complex paths may leave some stuck.
Native engine headers produce deprecation warnings; installed MSVC is newer than
the engine's preferred version. Supplied hoverbike pose assets report stale
source GUIDs. Vexa's inherited UDIM textures warn that only the first tile is
built with virtual texturing off; original configuration is retained. These
warnings did not prevent the recorded gameplay, but this is not release QA.
Four missing vendor/demo dependency references were already absent at source.
Docker is unavailable; a minimal container syntax workflow is supplied. Native
Unreal requires the installed Windows engine; no host packages were installed.
