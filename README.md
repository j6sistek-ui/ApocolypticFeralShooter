# AFS

UE 5.8 zombie shooter prototype (module `HoverFlight`) on the Zombie Engine Studio plugin. The mode in focus is
**NYC Survival**: wave-based, third-person, mortal, on `L_NYC_Survival`.

This repository holds **source, scripts and docs only**. Purchased content, generated assets and local configuration
stay on the owner's machine (`Content/`, `SourceAssets/`, `Saved/` are ignored).

Start with `Docs/CONTINUITY.md`, then `Docs/SCOPE.md`, `Docs/RULES.md`, `Docs/OPEN_ISSUES.md`, `Docs/LESSONS.md`.
